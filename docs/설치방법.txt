================================================================
 사업관리 대시보드 — 설치 방법
================================================================

 이 폴더를 처음 받으신 분을 위한 안내입니다.
 순서대로 따라 하시면 됩니다.


┌──────────────────────────────────────────────────────────────┐
│ 먼저 준비해 주세요                                            │
└──────────────────────────────────────────────────────────────┘

  Python      3.12 이상       필수
  Node.js     20 이상         필수 (화면을 만들 때 한 번만 씁니다)

  PostgreSQL  16 이상       필수 (서버에 설치)

  개발 PC 에서 시험만 해 볼 때는 PostgreSQL 없이도 됩니다.
  그때는 4단계를 건너뛰고 SQLite 파일을 그대로 씁니다.

  설치되어 있는지 확인:

      python3 --version
      node --version


┌──────────────────────────────────────────────────────────────┐
│ 설치 (5단계, 10분이면 됩니다)                                 │
└──────────────────────────────────────────────────────────────┘


─── 1단계.  화면 만들기 ────────────────────────────────────────

    cd frontend
    npm install
    npm run build
    cd ..

  → frontend/dist 폴더가 생깁니다. 이게 실제 화면입니다.

  ※ 이 폴더에는 만들어진 화면이 들어 있지 않습니다.
    (소스만 들어 있고, 만드는 것은 각자 환경에서 합니다)

  ※ 인터넷이 안 되는 서버라면, 인터넷 되는 PC 에서 위 명령을 돌린 뒤
    frontend/dist 폴더만 서버의 같은 위치로 복사하면 됩니다.


─── 2단계.  파이썬 준비 ────────────────────────────────────────

    python3 -m venv .venv
    .venv/bin/pip install -r requirements.txt

  Windows 라면:

    python -m venv .venv
    .venv\Scripts\pip install -r requirements.txt


─── 3단계.  설정 파일 만들기 ───────────────────────────────────

    cp .env.example .env
    .venv/bin/python scripts/set_password.py

  set_password.py 를 돌리면 로그인 비밀번호를 정할 수 있습니다.
  입력한 비밀번호는 암호화되어 .env 에 저장되고, 원문은 남지 않습니다.

  그다음 .env 파일을 열어 SECRET_KEY 를 바꿔 주세요.
  (로그인 쿠키를 암호화하는 값입니다. 기본값 그대로 두면 위험합니다)

  만드는 법:

      .venv/bin/python -c "import secrets;print(secrets.token_urlsafe(48))"

  나온 값을 .env 의 SECRET_KEY= 뒤에 붙여넣습니다.


─── 4단계.  데이터베이스 (PostgreSQL) ──────────────────────────

  ※ 개발 PC 에서 시험만 할 때는 이 단계를 건너뛰세요.
    .env 를 그대로 두면 SQLite 파일로 돌아갑니다.

  1) PostgreSQL 16 을 설치합니다. 설치본이 Windows 서비스로
     자동 등록되므로 재부팅 후에도 알아서 켜집니다.

  2) 이 프로그램이 쓸 계정과 데이터베이스를 만듭니다.
     (psql 또는 pgAdmin 에서)

         CREATE USER bizdash WITH PASSWORD '정한비밀번호';
         CREATE DATABASE bizdash OWNER bizdash;

  3) .env 의 DATABASE_URL 을 아래처럼 바꿉니다.

         DATABASE_URL=postgresql+psycopg://bizdash:정한비밀번호@localhost:5432/bizdash

  4) 바깥에서 데이터베이스에 직접 붙지 못하게 막아 둡니다.
     postgresql.conf 의 listen_addresses 를 localhost 로 둡니다.
     (설치 기본값이 localhost 이므로 대개 그대로 두면 됩니다)

  표(테이블)는 처음 실행할 때 자동으로 만들어집니다.

  백업은 하루 한 번 pg_dump 로 받아 두세요.

         pg_dump -U bizdash -Fc bizdash > bizdash_2026-08-31.dump

  ※ 받아 두는 것보다 '되돌려 보는 것' 이 중요합니다.
    처음 한 번은 다른 폴더에 복구해 보고 자료가 살아나는지
    확인해 두세요. 그래야 진짜 백업입니다.


─── 5단계.  실행 ───────────────────────────────────────────────

    cd backend
    ../.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000

  Windows 라면:

    cd backend
    ..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000

  브라우저에서 아래 주소로 들어갑니다.

      http://localhost:8000              (같은 PC 에서)
      http://서버주소:8000                (다른 PC 에서)

  3단계에서 정한 비밀번호로 로그인하면 됩니다.


┌──────────────────────────────────────────────────────────────┐
│ 처음 들어가면 이렇게 하세요                                   │
└──────────────────────────────────────────────────────────────┘

  1. [사업 현황 (공고)] → [지금 수집]
       기관 4곳에서 공고를 받아옵니다. 300건 이상, 1분 이내.

  2. [신규 사업 등록]
       관리할 사업을 등록합니다.
       공고 목록에서 [사업 등록] 을 눌러도 됩니다.
       (공고명·발주처·금액이 자동으로 채워집니다)


┌──────────────────────────────────────────────────────────────┐
│ 서버에서 계속 돌리려면 (Windows)                              │
└──────────────────────────────────────────────────────────────┘

  위 5단계는 창을 닫으면 멈춥니다.
  재부팅 후에도 자동으로 켜지게 하려면 서비스로 등록합니다.


  1) .env 운영값 확인

     · APP_PASSWORD_HASH   3단계에서 정한 값이 들어 있어야 합니다
     · SECRET_KEY          기본값이면 반드시 바꿉니다
     · CORS_ORIGINS        비웁니다 (한 서버가 화면까지 내보내므로 불필요)
     · COOKIE_SECURE       http 로 쓸 것이면 false 그대로 둡니다


  2) 먼저 확인할 것 두 가지

     · 서버 PC 의 IP 가 고정인지 확인하세요.
       자동 할당(DHCP)이면 재부팅할 때 주소가 바뀌어서
       쓰는 사람들의 즐겨찾기가 한꺼번에 깨집니다.

     · 쓰려는 포트가 비어 있는지 확인합니다.
       Windows 는 IIS 등이 80 번을 이미 쓰고 있는 경우가 많습니다.

           netstat -ano | findstr ":80 "

       무언가 나오면 그 포트는 쓸 수 없습니다.
       80 을 쓰는 쪽을 끄거나, 8000 번을 쓰세요.


  3) WinSW 로 서비스 등록

     WinSW 는 아무 프로그램이나 Windows 서비스로 만들어 주는 도구입니다.
     github.com/winsw/winsw 에서 받습니다.

     받은 파일을 bizdash-service.exe 로 이름을 바꿔 설치 폴더에 두고,
     같은 폴더에 bizdash-service.xml 을 아래 내용으로 만듭니다.
     (경로와 포트는 실제 환경에 맞게 고쳐 주세요)

         <service>
           <id>bizdash</id>
           <name>사업관리 대시보드</name>
           <description>사업 진척 · 예산 관리 대시보드</description>

           <executable>C:\bizdash\.venv\Scripts\python.exe</executable>
           <arguments>-m uvicorn app.main:app --host 0.0.0.0 --port 80</arguments>
           <workingdirectory>C:\bizdash\backend</workingdirectory>

           <!-- 이것이 없으면 한글 로그를 만나는 순간 서버가 멈춥니다 -->
           <env name="PYTHONUTF8" value="1"/>

           <onfailure action="restart" delay="5 sec"/>
           <log mode="roll-by-size"/>
         </service>

     관리자 명령 창에서 등록하고 시작합니다.

         bizdash-service.exe install
         bizdash-service.exe start

     상태 확인 · 중지 · 등록 해제:

         bizdash-service.exe status
         bizdash-service.exe stop
         bizdash-service.exe uninstall

     로그는 같은 폴더에 bizdash-service.out.log 로 쌓입니다.


  4) 방화벽 열기

     이 작업을 하지 않으면 서버 PC 에서만 화면이 보이고
     다른 PC 에서는 접속되지 않습니다.
     Windows 방화벽이 들어오는 연결을 기본으로 막기 때문입니다.

     관리자 PowerShell 에서 (대역과 포트는 실제 환경에 맞게):

         New-NetFirewallRule -DisplayName "사업관리 대시보드" `
           -Direction Inbound -Protocol TCP -LocalPort 80 `
           -Action Allow -RemoteAddress 10.20.150.0/23

     마지막 -RemoteAddress 가 '사내에서만 접속' 을 만드는 부분입니다.
     이 값을 빼면 어디서나 접속할 수 있게 열립니다.


  5) 접속 확인

     다른 PC 의 브라우저에서 서버 주소를 넣어 봅니다.

         http://10.20.151.119           (80 번을 쓸 때)
         http://10.20.151.119:8000      (8000 번을 쓸 때)

     공고 수집은 서버가 대신 합니다. 쓰는 사람 PC 는 인터넷이
     안 되어도 되고, 서버 PC 만 아래 4곳에 나갈 수 있으면 됩니다.


  6) 백업 자동화

     PostgreSQL 은 파일 복사로 백업되지 않습니다. pg_dump 를 씁니다.
     아래를 backup.bat 으로 만들고 작업 스케줄러에 매일 등록하세요.

         @echo off
         set D=%date:~0,4%-%date:~5,2%-%date:~8,2%
         "C:\Program Files\PostgreSQL\16\bin\pg_dump.exe" ^
           -U bizdash -Fc bizdash > "D:\backup\bizdash_%D%.dump"

     ※ 받아만 두고 끝내지 마세요.
       처음 한 번은 실제로 복구해 보고 자료가 살아나는지
       확인해야 진짜 백업입니다.


┌──────────────────────────────────────────────────────────────┐
│ 서버에서 계속 돌리려면 (리눅스)                               │
└──────────────────────────────────────────────────────────────┘

  위 5단계는 터미널을 닫으면 멈춥니다.
  재부팅 후에도 자동으로 켜지게 하려면 아래처럼 등록합니다.

  /etc/systemd/system/bizdash.service 파일을 만듭니다.
  (경로와 사용자 이름은 실제 환경에 맞게 고쳐 주세요)

      [Unit]
      Description=사업관리 대시보드
      After=network.target

      [Service]
      User=bizdash
      WorkingDirectory=/opt/bizdash/backend
      EnvironmentFile=/opt/bizdash/.env
      ExecStart=/opt/bizdash/.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
      Restart=always
      RestartSec=5

      [Install]
      WantedBy=multi-user.target

  등록하고 시작합니다.

      sudo systemctl daemon-reload
      sudo systemctl enable --now bizdash
      sudo systemctl status bizdash

  로그 보기:

      sudo journalctl -u bizdash -f


┌──────────────────────────────────────────────────────────────┐
│ https 로 서비스하려면 (선택)                                  │
└──────────────────────────────────────────────────────────────┘

  앞단에 Nginx 를 두고 8000 포트로 넘겨 주시면 됩니다.

      location / {
          proxy_pass http://127.0.0.1:8000;
          proxy_set_header Host $host;
          proxy_set_header X-Forwarded-Proto $scheme;
      }

  이 경우 .env 에서 COOKIE_SECURE=true 로 바꿔 주세요.


┌──────────────────────────────────────────────────────────────┐
│ 문제가 생기면                                                 │
└──────────────────────────────────────────────────────────────┘

  ▷ 화면이 안 뜨고 글자만 나옵니다
      1단계(화면 만들기)를 안 하셨을 가능성이 큽니다.
      frontend/dist 폴더가 있는지 확인해 주세요.

  ▷ 공고 수집이 안 됩니다
      서버가 외부 인터넷에 나갈 수 있어야 합니다.
      아래 4곳에 접속되는지 확인해 주세요.
          www.khidi.or.kr    www.kohi.or.kr
          www.khis.kr        www.ntis.go.kr

  ▷ 서비스는 켜졌는데 다른 PC 에서 접속이 안 됩니다
      방화벽 규칙을 넣지 않았을 가능성이 큽니다. 위 4) 를 보세요.
      서버 PC 에서 http://localhost 는 되는데 다른 PC 만 안 되면
      거의 방화벽입니다.

  ▷ 서비스가 켜지자마자 꺼집니다 (Windows)
      bizdash-service.out.log 를 열어 보세요.
      한글이 깨진 자리에서 멈춰 있으면 xml 의 PYTHONUTF8 설정이
      빠진 것입니다.

  ▷ 비밀번호를 잊었습니다
      .venv/bin/python scripts/set_password.py 로 다시 정하면 됩니다.

  ▷ 로그인 화면으로 돌아가고 싶습니다
      주소 뒤에 ?logout 을 붙입니다.  예) http://localhost:8000/?logout

  ▷ 잘 돌아가는지 확인하고 싶습니다
      cd backend && ../.venv/bin/python -m pytest
      → 72건 전부 통과하면 정상입니다.
