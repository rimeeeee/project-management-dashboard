# 회의록 양식

실제로 쓰는 회의록 양식 파일을 여기에 둡니다.
`backend/app/services/minutes_doc.py` 가 이 양식을 보고 문서를 만듭니다.

## 넣는 법

이 폴더에 파일을 그대로 넣으면 됩니다. hwpx · hwp · docx · 이미지 어느 것이든
괜찮습니다. 양식이 바뀌면 새 파일로 바꿔 넣고, 무엇이 달라졌는지 아래에
한 줄 적어 주세요.

## 지금 만들고 있는 모양

```
                    회 의 록

  회 의 명 | (회의명)
  일    시 | 2026년 09월 08일
  장    소 | (장소)
  참 석 자 | 홍길동, 김보건, 이약사

  회의내용
   • (내용 한 줄)
   • (내용 한 줄)

  회의 사진
   (사진이 있으면 원본 비율로 붙습니다)
```

문서는 docx 로 만듭니다. 한글(HWP)에서도 열립니다. hwpx 로 바로 만들지
않는 것은 파이썬에서 hwpx 를 제대로 다룰 라이브러리가 사실상 없기
때문입니다.
