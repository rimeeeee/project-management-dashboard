  Python(FastAPI) + React 로 만든 웹 서비스입니다.
  데이터베이스는 PostgreSQL 을 씁니다.

  화면과 서버가 한 프로그램에 들어 있어서
  · 열어야 하는 포트는 8000 하나뿐입니다
  · Apache/Nginx 같은 웹서버를 따로 두지 않아도 됩니다


┌──────────────────────────────────────────────────────────────┐
│ 서버 — Python                                                 │
└──────────────────────────────────────────────────────────────┘

  FastAPI          0.141.1   웹 프레임워크
  Uvicorn          0.52.4    웹 서버
  SQLAlchemy       2.0.52    데이터베이스 접근
  Alembic          1.19.1    데이터베이스 구조 변경 관리
  Pydantic         2.13.4    입력값 검증
  psycopg          3.3.4     PostgreSQL 연결
  APScheduler      3.11.3    공고 자동 수집 예약
  argon2-cffi      25.1.0    비밀번호 암호화
  itsdangerous     2.2.0     로그인 쿠키 위조 방지

  전체 목록: backend/requirements.txt


┌──────────────────────────────────────────────────────────────┐
│ 화면 — React                                                  │
└──────────────────────────────────────────────────────────────┘

  React            18.3.1
  TypeScript       5.9.3
  Vite             5.4.21    빌드 도구

  · Node.js 는 화면을 만들 때만 씁니다.
    만들어진 결과물을 Python 서버가 내보내므로,
    운영 중에는 Node 프로세스가 돌지 않습니다.

  · 상태관리·UI 라이브러리를 쓰지 않았습니다.
    확정된 디자인 시안을 그대로 옮긴 것이라,
    외부 UI 라이브러리를 섞으면 글자 크기·색이 틀어집니다.

  · 사용자가 내려받는 양: 약 130KB (압축 기준)


┌──────────────────────────────────────────────────────────────┐
│ 데이터베이스                                                  │
└──────────────────────────────────────────────────────────────┘

  운영: PostgreSQL 14 이상
  간단히 쓸 때: SQLite (파일 하나, 설치 불필요)

  같은 코드가 둘 다 지원합니다. .env 의 DATABASE_URL 하나로 전환됩니다.
  표 14개 (사업 · 보고회차 · 집행내역 · 성과지표 · 공고 등)
  표는 서비스가 처음 시작할 때 자동으로 만들어집니다.

  · 읽기만 하고, 이쪽 자료를 내보내지 않습니다
  · 기본은 화면에서 [지금 수집] 을 누를 때만 실행됩니다
    (.env 에서 자동 실행으로 바꿀 수 있습니다)

  ★ 서버가 위 4개 주소로 나갈 수 있어야 동작합니다.


┌──────────────────────────────────────────────────────────────┐
│ 로그인                                                        │
└──────────────────────────────────────────────────────────────┘

  팀 공용 비밀번호 한 개로 들어갑니다. 개인 계정은 없습니다.
  비밀번호는 Argon2 로 암호화해 저장하며 원문은 남지 않습니다.
  로그인하면 12시간 유지됩니다.

  나중에 사내 계정(LDAP/SSO)으로 바꿀 수 있도록
  로그인 부분만 따로 떼어 두었습니다.


┌──────────────────────────────────────────────────────────────┐
│ 보안                                                          │
└──────────────────────────────────────────────────────────────┘

  · 비밀번호는 Argon2 로 암호화 (원문 저장 안 함)
  · 로그인 쿠키는 서명되어 있어 위조할 수 없습니다
  · 로그인하지 않으면 어떤 자료도 조회되지 않습니다
  · 주소를 조작해 폴더 밖 파일을 가져가는 시도를 차단합니다
    (자동 테스트로 계속 확인합니다)

  ★ 설치할 때 반드시 하셔야 하는 것 2가지
      1. scripts/set_password.py 로 비밀번호 정하기
      2. .env 의 SECRET_KEY 를 기본값에서 바꾸기

  자동 테스트 72건        cd backend && ../.venv/bin/python -m pytest

  개발 환경에서 확인한 것
    · Python 서버 하나로 화면까지 서비스되는 구성으로 실제 구동
    · 화면 표시 · 로그인 · 공고 300건 이상 수집 정상
    · 빈 데이터베이스에서 표 자동 생성 후 정상 동작

  아직 확인하지 못한 것
    · PostgreSQL 연결 (개발 중에는 SQLite 로만 확인했습니다)
      첫 설치 때 함께 확인해 주시면 좋겠습니다.
