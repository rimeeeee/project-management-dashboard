================================================================
 사업관리 대시보드 — 기술 스택
================================================================


  Python(FastAPI) + React 로 만든 웹 서비스입니다.
  자료는 PostgreSQL 에 저장됩니다.
  (개발 PC 에서는 설치 없이 SQLite 파일을 씁니다)

  화면과 서버가 한 프로그램에 들어 있어서
  · 밖에서 열어야 하는 포트는 하나뿐입니다
  · PostgreSQL 은 같은 PC 안에서만 연결하므로 열지 않습니다


┌──────────────────────────────────────────────────────────────┐
│ 서버 — Python 3.12 이상                                       │
└──────────────────────────────────────────────────────────────┘

  FastAPI          0.141.1   웹 프레임워크
  Uvicorn          0.52.4    포트를 열고 요청을 받는 서버
  SQLAlchemy       2.0.52    데이터베이스 접근
  psycopg          3.3.4     PostgreSQL 연결
  Alembic          1.19.1    표 구조가 바뀔 때 반영
  Pydantic         2.13.4    입력값 검증
  argon2-cffi      25.1.0    비밀번호 암호화
  itsdangerous     2.2.0     로그인 상태 유지·검증

  전체 목록: requirements.txt


┌──────────────────────────────────────────────────────────────┐
│ 화면 — React                                                  │
└──────────────────────────────────────────────────────────────┘

  React            18.3.1
  TypeScript       5.9.3
  Vite             5.4.21    빌드 도구

  Node.js 는 화면을 만들 때만 씁니다.
  만들어진 결과물을 Python 서버가 내보내므로, 운영 중에는 돌지 않습니다.



┌──────────────────────────────────────────────────────────────┐
│ 데이터베이스 — PostgreSQL                                     │
└──────────────────────────────────────────────────────────────┘

  운영 서버는 PostgreSQL 16 을 씁니다.
  개발 PC 에서는 설치하지 않고 SQLite 파일(data/bizdash.db)을 씁니다.
  어느 쪽을 쓸지는 .env 의 DATABASE_URL 한 줄로 정합니다.

  표 14개 (사업 · 보고회차 · 집행내역 · 성과지표 · 공고 등)
  표는 서비스가 처음 시작할 때 자동으로 만들어집니다.

┌──────────────────────────────────────────────────────────────┐
│ 로그인과 보안                                                 │
└──────────────────────────────────────────────────────────────┘

  팀 공용 비밀번호 한 개로 들어갑니다. 개인 계정은 없습니다.
  로그인하면 12시간 유지됩니다.

  · 비밀번호는 Argon2 로 암호화해 저장하며 원문은 남지 않습니다
  · 로그인 쿠키에는 서명이 붙습니다. 이 서명이 로그인의 핵심으로,
    없으면 쿠키를 직접 고쳐 비밀번호 없이 들어올 수 있습니다
  · 로그인하지 않으면 어떤 자료도 조회되지 않습니다
  · 주소를 조작해 폴더 밖 파일을 가져가는 시도를 차단합니다

  자동 테스트 72건으로 위 내용을 계속 확인합니다.

      cd backend && ../.venv/bin/python -m pytest
