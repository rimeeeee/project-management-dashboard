================================================================
 배포 방법
================================================================

  준비물: Docker, Docker Compose

  1) 설정 파일 만들기
       cp .env.example .env

  2) 비밀번호 정하기
       python scripts/set_password.py
       → .env 의 APP_PASSWORD_HASH 에 자동으로 들어갑니다

  3) .env 에서 아래 3가지를 반드시 바꾸기
       SECRET_KEY        아무 긴 문자열 (로그인 쿠키 암호화에 씁니다)
       POSTGRES_PASSWORD 데이터베이스 비밀번호
       COOKIE_SECURE     https 로 서비스하면 true

  4) 실행
       docker compose up -d --build

  5) 접속 확인
       http://서버주소:8000

  ※ https 로 서비스하려면 앞단에 nginx 등을 두고
     8000 포트로 넘겨 주시면 됩니다.


================================================================
 전산실에 확인 요청드립니다
================================================================

  1. 서버에서 외부 인터넷으로 나갈 수 있습니까?
     ★ 가장 중요합니다.
       공고 수집이 이 서비스의 핵심 기능인데,
       막혀 있으면 아예 동작하지 않습니다.
       필요하면 위 4개 도메인만 열어 주셔도 됩니다.

  2. 고정 IP 가 있습니까?
     기관 사이트가 IP 등록을 요구하는 경우에 대비해 여쭙습니다.
     현재는 인증키 없이 접근되고 있습니다.

  3. https 인증서를 붙일 수 있습니까?
     비밀번호를 주고받으므로 https 를 권장드립니다.
