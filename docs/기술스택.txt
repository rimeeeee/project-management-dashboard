================================================================
 설치 방법
================================================================

 아래 예시는 /opt/bizdash 에 설치한다고 가정했습니다.
 경로와 사용자 이름은 실제 환경에 맞게 바꿔 주세요.


─────────────────────────────────────────────────────────────
 1단계.  화면 만들기   (한 번만)
─────────────────────────────────────────────────────────────

    cd frontend
    npm ci
    npm run build
    cd ..

  → frontend/dist/ 폴더가 만들어집니다.

  ※ 서버에 인터넷이 없거나 Node 설치가 어려운 경우
    인터넷이 되는 PC 에서 위 명령을 돌린 뒤,
    만들어진 frontend/dist/ 폴더만 서버의 같은 위치로 복사하면 됩니다.
    (이후 단계에 Node 는 필요 없습니다)


─────────────────────────────────────────────────────────────
 2단계.  파이썬 준비
─────────────────────────────────────────────────────────────

    python3 -m venv .venv
    .venv/bin/pip install -r backend/requirements.txt


─────────────────────────────────────────────────────────────
 3단계.  데이터베이스 만들기
─────────────────────────────────────────────────────────────

  PostgreSQL 에 접속해 데이터베이스와 계정을 만듭니다.

    CREATE DATABASE bizdash;
    CREATE USER bizdash WITH PASSWORD '정하실_비밀번호';
    GRANT ALL PRIVILEGES ON DATABASE bizdash TO bizdash;

  PostgreSQL 15 이상이면 아래도 함께 실행해 주세요.

    \c bizdash
    GRANT ALL ON SCHEMA public TO bizdash;

  ※ 표는 서비스가 처음 시작할 때 자동으로 만들어집니다.


─────────────────────────────────────────────────────────────
 4단계.  설정 파일 만들기
─────────────────────────────────────────────────────────────

    cp .env.example .env
    .venv/bin/python scripts/set_password.py     ← 로그인 비밀번호

  .env 를 열어 아래 3가지를 채웁니다.

    DATABASE_URL=postgresql+psycopg://bizdash:정하신_비밀번호@localhost:5432/bizdash

    SECRET_KEY=아무_긴_문자열
      만드는 법:
      .venv/bin/python -c "import secrets;print(secrets.token_urlsafe(48))"

    COOKIE_SECURE=true        ← https 로 서비스하는 경우에만


─────────────────────────────────────────────────────────────
 5단계.  실행해 보기
─────────────────────────────────────────────────────────────

    cd backend
    ../.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000

  브라우저에서  http://서버주소:8000  으로 접속되면 성공입니다.
  확인 후 Ctrl+C 로 종료하고 6단계로 넘어갑니다.


─────────────────────────────────────────────────────────────
 6단계.  서비스로 등록  (재부팅 후 자동 실행)
─────────────────────────────────────────────────────────────

  /etc/systemd/system/bizdash.service 파일을 아래 내용으로 만듭니다.

    [Unit]
    Description=사업관리 대시보드
    After=network.target postgresql.service

    [Service]
    User=bizdash
    WorkingDirectory=/opt/bizdash/backend
    EnvironmentFile=/opt/bizdash/.env
    ExecStart=/opt/bizdash/.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
    Restart=always
    RestartSec=5

    [Install]
    WantedBy=multi-user.target

  등록하고 시작합니다.

    systemctl daemon-reload
    systemctl enable --now bizdash
    systemctl status bizdash

  로그 보기:
    journalctl -u bizdash -f


─────────────────────────────────────────────────────────────
 7단계.  첫 사용
─────────────────────────────────────────────────────────────

    1) http://서버주소:8000  접속 후 로그인
    2) [사업 현황 (공고)] → [지금 수집]
       → 공고 300건 이상 들어옵니다 (1분 이내)
    3) [신규 사업 등록] 으로 실제 사업 등록


─────────────────────────────────────────────────────────────
 (선택)  https 로 서비스하려면
─────────────────────────────────────────────────────────────

  앞단에 Nginx 를 두고 8000 포트로 넘겨 주시면 됩니다.

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

  이 경우 .env 에서 COOKIE_SECURE=true 로 바꿔 주세요.


================================================================
 전산실에 확인 요청드립니다
================================================================

  1. 서버에서 외부 인터넷으로 나갈 수 있습니까?
     ★ 가장 중요합니다.
       공고 수집이 이 서비스의 핵심 기능인데,
       막혀 있으면 아예 동작하지 않습니다.
       필요하면 위 4개 도메인만 열어 주셔도 됩니다.

  2. 고정 IP 가 있습니까?
     기관 사이트가 IP 등록을 요구하는 경우에 대비해 여쭙습니다.
     현재는 인증키 없이 접근되고 있습니다.

  3. https 인증서를 붙일 수 있습니까?
     비밀번호를 주고받으므로 https 를 권장드립니다.


================================================================
 참고 사항
================================================================

  · 병원 내부 자료를 외부로 보내지 않습니다.
    외부 통신은 위 4개 기관 사이트에서 '읽어오는' 것뿐입니다.

  · 개발 환경에서 아래까지 확인했습니다.
      - 위 방식(Python 서버 하나로 화면까지 서비스)으로 실제 구동
      - 화면 표시 · 로그인 · 공고 337건 조회 정상
    다만 그때 데이터베이스는 SQLite 였습니다.
    PostgreSQL 연결은 서버에서 처음 하게 되므로,
    첫 기동 시 함께 확인해 주시면 감사하겠습니다.

  · 문서·소스 파일은 서비스에 포함되지 않습니다.
    사용자에게 나가는 것은 화면 파일(HTML·JS·CSS·글꼴·로고)뿐이며,
    폴더 밖 파일을 요청해도 차단되는지 자동 테스트로 확인하고 있습니다.

  · 자동 테스트 72건이 포함되어 있습니다.
      cd backend && ../.venv/bin/python -m pytest
