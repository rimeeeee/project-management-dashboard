 사업관리 대시보드 — 기술 스택
================================================================


  Python(FastAPI) + React 로 만든 웹 서비스입니다.
  자료는 SQLite 파일 하나에 저장됩니다.

  화면과 서버가 한 프로그램에 들어 있어서
  · 열어야 하는 포트는 8000 하나뿐입니다
  · Apache/Nginx 같은 웹서버를 따로 두지 않아도 됩니다

  FastAPI          0.141.1   웹 프레임워크
  Uvicorn          0.52.4    웹 서버
  SQLAlchemy       2.0.52    데이터베이스 접근
  Alembic          1.19.1    표 구조가 바뀔 때 반영
  Pydantic         2.13.4    입력값 검증
  APScheduler      3.11.3    공고 자동 수집 예약
  argon2-cffi      25.1.0    비밀번호 암호화
  itsdangerous     2.2.0     로그인 쿠키 위조 방지

  전체 목록: backend/requirements.txt

┌──────────────────────────────────────────────────────────────┐
│ 로그인과 보안                                                 │
└──────────────────────────────────────────────────────────────┘

  팀 공용 비밀번호 한 개로 들어갑니다. 개인 계정은 없습니다.
  로그인하면 12시간 유지됩니다.

  · 비밀번호는 Argon2 로 암호화해 저장하며 원문은 남지 않습니다
  · 로그인 쿠키는 서명되어 있어 위조할 수 없습니다
  · 로그인하지 않으면 어떤 자료도 조회되지 않습니다
  · 주소를 조작해 폴더 밖 파일을 가져가는 시도를 차단합니다

  자동 테스트 72건으로 위 내용을 계속 확인합니다.

      cd backend && ../.venv/bin/python -m pytest
