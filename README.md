# 사업관리 대시보드

여러 사업의 **진행 상황과 예산 집행을 한눈에 보는** 웹 프로그램입니다.
사업마다 회차를 정해 기록해 두면, 지금 계획보다 앞서는지 처졌는지를
사람이 계산하지 않아도 화면이 알려 줍니다.

기관 네 곳의 사업 공고도 함께 모아 보여 줍니다.

---

## 무엇을 할 수 있나요

### 사업이 계획대로 가고 있는지 바로 압니다

사업 기간과 진행 단계를 넣어 두면 **계획 진행률**을 날짜로 계산합니다.
실제 진행률과 견주어 사업마다 상태를 붙입니다.

| 표시 | 뜻 |
|---|---|
| 정상 | 계획대로 가고 있습니다 |
| 점검 필요 | 계획보다 5%p 넘게 처졌거나, 해결 안 된 확인사항이 있습니다 |
| 조치 필요 | 계획보다 15%p 넘게 처졌습니다 |

여러 사업을 맡고 있어도 **어느 사업을 먼저 챙겨야 하는지** 목록에서 바로 보입니다.

### 회차마다 기록합니다

사업의 보고 주기를 **주간 · 격주 · 월간** 중에 고르면, 그 주기대로 회차가
자동으로 만들어집니다. 회차마다 이런 것을 적습니다.

- 진행 단계와 주요 추진과제 체크
- 집행액 (비목별)
- 활동 요약과 확인사항
- 성과지표 실적

한 번 적은 내용은 고쳐도 **이전 내용이 남습니다.** 지운 회차도 기록이 남아
"이 숫자가 언제 어떻게 바뀌었는지" 확인할 수 있습니다.

### 예산이 얼마나 남았는지 봅니다

비목별로 배정액과 집행액을 넣으면 집행률과 잔액을 계산합니다.
전체 사업을 합한 총 사업비 · 총 집행액도 첫 화면에 나옵니다.

### 사업 공고를 모아서 봅니다

[지금 수집] 을 누르면 아래 네 곳에서 공고를 받아옵니다. 300건 이상을
1분 안에 가져옵니다.

- 한국보건산업진흥원
- 한국보건복지인재원
- 한국보건의료정보원
- NTIS 국가R&D 통합공고

접수중 · 접수예정 · 마감으로 나눠 보고, 관심 공고에 별표를 달 수 있습니다.
카드 보기와 목록 보기를 오갈 수 있고, 마음에 드는 공고는 **[사업 등록] 한 번으로
관리 대상 사업이 됩니다** (공고명 · 발주처 · 금액이 자동으로 채워집니다).

### 일정을 달력으로 봅니다

사업 기간이 달력에 형광펜처럼 칠해지고, 회차 마감일과 할 일 기한이 함께
표시됩니다.

## 화면 구성

| 메뉴 | 하는 일 |
|---|---|
| **전체 사업 현황** | 모든 사업의 상태 · 진행률 · 집행률을 한 화면에. 일정 달력도 함께 |
| **사업별 대시보드** | 사업 하나를 자세히. 회차 입력도 여기서 |
| **신규 사업 등록** | 관리할 사업을 추가 |
| **사업 현황 (공고)** | 기관 네 곳의 공고 모아 보기 |

---

## 쓰기 전에 알아 두면 좋은 것

- **팀에서 공용 비밀번호 하나로 들어갑니다.** 개인 계정은 없습니다.
  한 번 로그인하면 12시간 유지됩니다.
- **두 사람이 같은 회차를 동시에 고치면** 조용히 덮어쓰지 않고,
  먼저 저장한 사람이 있다고 알려 줍니다.
- **입력 내역이 있는 사업은 보고 주기를 바꿀 수 없습니다.** 주기가 바뀌면
  이미 저장된 회차가 다른 기간을 가리키게 되기 때문입니다.
- **날짜는 한국 시간 기준**입니다.
- **금액은 억 단위로 입력**합니다 (예: 38억 → `38`).
