# 프로토타입 대조 검증

옮긴 로직이 프로토타입과 같은 값을 내는지 확인합니다.
계산 규칙을 건드렸다면 반드시 다시 돌려 보세요.

```bash
.venv/bin/python scripts/verify/run.py
```

확인하는 것

| | |
|---|---|
| 회차 계산 | 주간·격주·월간 × 900일 = 2,700건을 시안 JS 와 문자열까지 대조 |
| 대시보드 숫자 | 진행률·계획 진척률·상태·집행액·잔액·성과지표·비목별 사용액 |

날짜는 한국시간으로 봅니다. 시안(자바스크립트)은 `new Date("2026-06-01")` 을
UTC 자정으로 읽는 문제가 있었지만, 그건 시안 쪽 버그라 따라가지 않았습니다.
| 시간대 영향 | UTC/KST 해석 차이가 계획 진척률에 얼마나 영향을 주는지 |

`js_*.js` 는 프로토타입 HTML 에서 해당 함수를 잘라내 그대로 실행하는 파일입니다.
로직을 다시 적지 않고 원본을 그대로 돌리므로, 대조의 기준이 흔들리지 않습니다.
